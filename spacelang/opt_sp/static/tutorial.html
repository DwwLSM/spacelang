First five minutes

1. Write something

Open the OPT_SP editor, keep Assembly as the mode and press Run. The default listing pushes two numbers, adds them and halts.

2. Read the trace

The visualizer shows the instruction being executed, the operand stack, the call stack, the heap and anything printed. Step through it with the arrow keys or the slider; nothing is hidden behind a debugger build.

3. See the encoded form

Open the Studio and type the same program as Python. Two more panes fill themselves: the assembly listing and the encoded .sp, where every token is a run of spaces. That is the artifact the language actually ships.

4. Change the low level, keep the mirror

Edit the assembly pane: swap OP 1 (add) for OP 2 (subtract). The Python pane is marked stale instead of being overwritten, because nothing turns a program back into Python. Press Sync with AI to have a model rewrite the mirror; the answer is only accepted if it compiles to the same instructions.

5. Run it without Python

The repository ships a standalone interpreter (native/spvm) and a compiler written in SpaceLang itself. Build them with native/build.ps1, then run any compiled .sp with no CPython in the loop.
