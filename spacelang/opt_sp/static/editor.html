Help

Tab inserts four spaces. With lines selected, Tab indents and Shift+Tab outdents; without a selection, Shift+Tab outdents the current line. Drag selected text to move it. Undo: Ctrl+Z / Cmd+Z; redo: Ctrl+Shift+Z / Cmd+Shift+Z or Ctrl+Y. Encoded source uses spaces and newlines. Download saves a copy; Overwrite replaces the loaded source file after confirmation.
